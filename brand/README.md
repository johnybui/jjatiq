# JJATiQ brand kit

The logo is two J's wrapped in an **@**, read as "JJ at". It covers the "JJAT" in JJATiQ.
Always write the name as **JJATiQ**, in one color. Don't highlight the "iQ".

## Which file to use

| Need | File |
|---|---|
| Logo on a dark background | `svg/jjatiq-logo-on-dark.svg`, `png/logo-on-dark-*.png` |
| Logo on a light background | `svg/jjatiq-logo-on-light.svg`, `png/logo-on-light-*.png` |
| Icon (rounded tile), avatars, in-app | `svg/jjatiq-mark.svg`, `png/mark-{16…1024}.png` |
| Symbol without the tile, on dark | `svg/jjatiq-glyph-color.svg`, `png/glyph-color-1024.png` |
| One-color symbol (white / dark) | `svg/jjatiq-glyph-white.svg`, `svg/jjatiq-glyph-dark.svg` |
| iOS App Store / app icon | `png/app-icon-ios-1024.png` (square, no transparency; iOS rounds the corners) |
| Google Play icon | `png/app-icon-play-512.png` |
| Android adaptive icon | foreground `png/android-foreground-432.png` (or `svg/jjatiq-android-foreground.svg`), background color `#13201C` |
| Android notification icon | `svg/jjatiq-glyph-white.svg` |

The wordmark text is converted to shapes, so the logos look right without the font installed.

## Colors

Full list in `colors.json`.

| Role | Hex |
|---|---|
| Background | `#0B1311` |
| Logo tile / cards | `#13201C` |
| Text | `#EAF4F0` |
| Mint (accent) | `#3EE6B0` |
| Text on mint | `#06231A` |

## Fonts

- Headings and wordmark: **Outfit** (SemiBold 600)
- Body: **Inter**

Both are free on Google Fonts.

## Rules

- Keep clear space around the logo of at least half the tile's width.
- Don't recolor, stretch, rotate or add effects to the logo.
- Use the mint only as an accent, not as a large background.
